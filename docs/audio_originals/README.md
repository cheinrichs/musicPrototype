# Untrimmed originals (not shipped)

Byte-for-byte copies of note samples as they were before
`tool/trim_note_start.py` cut their lead-in (2026-11-15). They live here,
outside `assets/`, so they never ship. To undo a trim, copy the file back
over its asset: for example, `notes/guitar/c3.mp3` goes back to
`assets/audio/notes/guitar/c3.mp3`.

The cut for each file is recorded in that library's PROVENANCE.md, or for
the bells, ATTRIBUTION.md.
